1. Number of confined layers → kz nodes

When a state is confined over N layers, the kz intensity has peaks at integer Brillouin-zone centers with exactly N−1 nodes between them. For N=1 there is only a single layer to interfere, so the intensity is broad and featureless.

2. Realistic model: surface Δzl and η-decay tail

The actual fitting model from SM Sec. 2. The top three layers (l=0,1,2) carry a surface-relaxation phase offset Δzl, and the deep layers (l=5–15) are modeled as an η-decay tail anchored at A4. Toggle the switch to compare with the ideal model, and use the sliders to vary Δz and η. The η-tail is most visible in the dxz/yz preset. Each blue dot shows its current amplitude Al.
